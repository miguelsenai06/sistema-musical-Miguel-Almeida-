

# 🎵 Sistema Musical-miguel almeida 

## 📌 Sobre o Projeto

O **Sistema Musical** é um projeto desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas, com o objetivo de criar um sistema web para organizar e gerenciar informações sobre músicas e artistas.

O projeto foi desenvolvido utilizando HTML e CSS, buscando criar uma interface organizada, simples e fácil de utilizar.

## 🎯 Objetivo

Desenvolver uma plataforma visual para gerenciamento de uma biblioteca musical, permitindo visualizar músicas, consultar artistas e acessar páginas de cadastro.

## 💻 Tecnologias Utilizadas

- HTML5 – Estruturação das páginas.
- CSS3 – Estilização e organização visual.
- Visual Studio Code – Ambiente de desenvolvimento.

## 📂 Estrutura do Projeto

```
Sistema-Musical/
│
├── index.html
├── biblioteca.html
├── cadastro_artista.html
├── cadastro_musica.html
├── styles.css
│
└── assets/
    └── Imagens do projeto
```

## ⚙️ Funcionalidades Desenvolvidas

- Página inicial com menu de navegação.
- Biblioteca musical com listagem de músicas.
- Busca e filtros por artista e gênero musical.
- Exibição de informações dos artistas.
- Links para acessar músicas no YouTube.
- Página de cadastro de artistas.
- Página de cadastro de músicas.
- Campos para adicionar fotos de artistas e capas de músicas.
- Interface com tabelas e botões de gerenciamento.

## 🎨 Interface

O sistema foi desenvolvido com foco na organização, facilidade de navegação e apresentação das informações musicais.

## 🚀 Como Executar o Projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server.

## 📚 Considerações Finais

O desenvolvimento do Sistema Musical proporcionou a aplicação prática dos conhecimentos adquiridos nas aulas de Desenvolvimento de Sistemas, principalmente na utilização de HTML e CSS.

O projeto representa uma etapa inicial da criação de um sistema de gerenciamento musical, que poderá receber novas funcionalidades e integrações futuramente.
